# AWS Cloud Mind Map

Interactive study mind map for AWS — 17 domains, click-to-expand nodes, global search, progress tracking.

## Preview

Open `index.html` in any modern browser. No build step, no server needed.

## What's inside

- **Landing page** (`index.html`) — radial mind map with 17 service domains, progress tracker, and global search.
- **17 section pages** (`sections/*.html`) — interactive collapsible mind maps. Click any node to expand/collapse. Drag to pan, scroll to zoom.
- **Shared assets** (`assets/`) — `data.js` holds all content, `mindmap.js` renders the interactive trees, `search.js` powers the global search, `styles.css` is the theme.

## Domains covered

Scaling · Databases · DNS · Containerization · Serverless · Data Analytics · Monitoring · Disaster Recovery · Compute · Access Control · CDN · Storage · App Integration & Messaging · Machine Learning · Security · VPC · Cost
